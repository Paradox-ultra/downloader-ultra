# Paradox Downloader

Paradox Downloader is a video and file downloader for Android by Paradox.

**[Download the latest release](https://github.com/chinmays-tanx09/paradox-downloader/releases/latest)** — get `Paradox_Downloader_v4.1.apk` from the Assets list and open it.

## Install

- Needs Android 8.0 or newer.
- Updating: install the new APK over the old one. Official builds are all signed with the same key, so your data is kept.
- "App not installed"? You probably have a copy signed by someone else. Uninstall it first, then install the APK from this page.

## What's new in v4.1

- WhatsApp channel welcome card: once per app start, an invite to the Paradox WhatsApp channel (Join channel / Later / Don't show again).
